# Reklam okuma

Rapor okunur. Kampanya bu skill ile değişmez.

## Akış

1. Hesap kimliğini `Desktop\HARİTA.md` bölüm 8’den al. Numarayı buraya kopyalama.
2. Yerel kanıt `Güner Ofis\04 Sosyal Medya\Reklam\Sümen Takımı` içindedir. Önce oradaki son tarihli dosyayı oku.
3. Google Ads MCP bağlıysa salt okuma sorgusu kullan. Resmi sunucu 16.10.2026 itibarıyla salt okumadır. Üçüncü parti yazma sunucusu bağlama.
4. Meta Ads MCP yazabildiği için bu işte bağlama.
5. Chrome profili de HARİTA bölüm 8’dedir. Yanlış profilde hesap açma.
6. Sonucu aynı reklam klasörüne kısa yaz: tarih, hesap, okunan dönem, fark, yapılmayan değişiklik.

## Değişmezler

- Bütçe, teklif, duraklatma ve yeni kampanya yok.
- Harcamayı veya dönüşümü uydurma. Dosya veya API dönmezse bilinmiyor yaz.
