# Gösterge sözlüğü
Her rapor dönem, veri kaynağı, güncellenme zamanı, para birimi ve kapsam filtresini gösterir. Veri yoksa “veri yok”; payda sıfırsa “hesaplanamaz” yazılır. Hedefler mevcut performans ölçüldükten sonra belirlenir.

| Gösterge | Hesap / kapsam | Sahip |
|---|---|---|
| Geciken iş | Rapor anında tamamlanmamış / iptal edilmemiş ve hedef tarihi geçmiş işler | YONETIM |
| Net ürün satışı | Tamamlanmış satış satırları − satır indirimleri − aynı kapsam iadeleri; vergi / kargo ayrı | FINANS |
| Açık alacak | Kayıtlı alacak − buna bağlanan tahsilat ve düzeltmeler; para birimi bazında | FINANS |
| Zamanında sevk oranı | Dönemde sevk edilmesi gerekenlerden taahhüt tarihine kadar taşıyıcıya teslim edilen / sevk edilmesi gereken; iptal kapsamı belirtilir | LOJISTIK |
| Stok farkı | Sayılan fiziksel miktar − kayıtlı fiziksel miktar; SKU / depo bazında | URUN_STOK |
| Sağlam üretim oranı | Kaliteyi geçen çıktı / incelenen toplam çıktı; ürün / dönem bazında | URETIM |
| İlk yanıt süresi | İlk yetkili yanıt zamanı − talep alınma zamanı; medyan, çalışma saati yöntemi belirtilir | MUSTERI |
| Kampanya getirisi oranı | Aynı kapsamda ilişkilendirilen gelir / gerçekleşen reklam harcaması; ilişkilendirme yöntemi açık | PAZARLAMA |
| AI ilk kabul oranı | İlk incelemede kabul edilen görev / ilk incelemesi tamamlanan görev | AI |
| Bağlantı güncelliği | Rapor zamanı − son başarılı aktarım; bağlantı bazında | TEKNOLOJI |
| Yaklaşan yükümlülük | Belirlenen tarih aralığında vadesi gelen açık sözleşme / bakım / idari işi | İlgili birim |
