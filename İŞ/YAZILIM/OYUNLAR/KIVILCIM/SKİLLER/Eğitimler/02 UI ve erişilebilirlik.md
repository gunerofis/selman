# 02 UI ve erişilebilirlik

Amaç: Referansa bağlı ekranları okunur, tutarlı ve dokunmayla kullanılabilir yapmak.

## Çalışma sırası

Unity dersinin UI/UX/IxD ayrımını oku. Ardından game-ui-frontend ve game-ui-ux; belirli sorunda UI UX Pro Max. Tüm tasarım sistemini yeniden üretme.

## Uygulama

1. Tek ekranın normal, seçili, kapalı, boş, yükleniyor ve hata durumlarını mevcut uygulamayla eşleştir.
2. 2. kademe sekmeyi, 3. kademe alt sekmeyi ve başka sayfaya geçişi ayır. Market Lonca ile hub Lonca'yı karıştırma.
3. Yazı taşması, dokunma hedefi, odak, geri dönüş, kaydırma ve pencere altında yanlış tıklamayı kontrol listesine al.
4. Bilgiyi yalnız renkle aktarma; okunabilir metin, hareket azaltma ve ses dışı geri bildirim seçeneklerini değerlendir.

## Bitiş ölçütü

Akışlar referansla eşleşir; gerçek ve taslak veriler ayrılır. Görsel denetim yalnız izin verilen aşamada yapılır.

## Kaynaklar

- [K06 — Unity — Get started with user interfaces](https://learn.unity.com/pathway/game-development/unit/user-interfaces/tutorial/get-started-with-user-interfaces-1-1): Kullanıcının verdiği UI/UX eğitimi; Unity uygulaması Kıvılcım'ın mevcut motoru değildir.
- [K07 — UI UX Pro Max — skills.sh](https://www.skills.sh/nextlevelbuilder/ui-ux-pro-max-skill/ui-ux-pro-max): Kullanıcının verdiği katalog sayfası; dosyalar asıl GitHub deposundan alındı.
- [K08 — UI UX Pro Max — kaynak](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): Dokunma, tipografi, yerleşim ve erişilebilirlik için arama verileri ve Python araçları.
- [K09 — Game UI Design Workflow](https://github.com/guiguiyan930-source/game-ui-design-workflow): Kullanıcının verdiği sekiz aşama skill'i, şablon, şema ve atlas araçları; çoğunlukla Çince.
- [K10 — OpenAI Game UI Frontend](https://github.com/openai/plugins/blob/main/plugins/game-studio/skills/game-ui-frontend/SKILL.md): Kullanıcının verdiği oyun HUD, menü ve DOM arayüz skill'i; tam Game Studio paketiyle saklandı.
- [K11 — Game Accessibility Guidelines](https://gameaccessibilityguidelines.com/full-list/): Kontrol, okunabilirlik, ses, bilişsel yük ve erişilebilir oyun seçenekleri.
- [K12 — WCAG 2.2](https://www.w3.org/TR/WCAG22/): Web arayüzünün odak, renk, hedef ve okunabilirlik ölçütleri; oyun tasarımının tamamı değildir.
- [K13 — MDN Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events): Dokunma, kalem ve fare olayları; input ve iptal durumları.

## Kullanıcı özeti

Dış skill'in dashboard, font veya 3D HUD varsayımları onaylı oyun estetiğini değiştirmez. Game UI Workflow üretim/atlas adımları ileriki asset aşamasınındır.
