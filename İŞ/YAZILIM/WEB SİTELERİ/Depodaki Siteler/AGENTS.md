# WEB çalışma kökü

Siteler `Sites/` altındadır. Ortak web sözleşmesi: `agent/AGENTS.md`.
Grok skill’leri `C:\Users\DELL\.grok\skills\` altındadır; bu klasördeki `.grok/skills` ona bağlanır. Hepsini birden çalıştırmak için `/web`.

| Klasör | Proje |
| --- | --- |
| `Sites/Kronora` | Kronora e-ticaret |
| `Sites/sweb` | sweb mağaza |
| `Sites/BUCURUKTOYS-TAM-PAKET-v32` | Bucuruktoys |
| `Sites/grok site` | Grok App Builder mağaza (kendi `.grok/skills` seti ayrı; web skill’leri `.agents/skills`) |
| `agent/` | Sözleşme, orijinal skill kaynakları, SEO notları |

Görevi ilgili site klasöründe yap. Kullanıcı istemedikçe siteler arasında dosya kopyalama veya canlı yayın yapma.
